## C. Preguntas para Legal de CAFIVER
1. ¿Qué tipos de documento requieren firma **avanzada/fiable** y cuáles bastan con firma electrónica simple?
2. ¿Qué documentos necesitan constancia NOM-151? (contratos con terceros, laborales, financieros, etc.)
3. ¿Cómo se identificará a cada tipo de firmante (empleado, proveedor, cliente)? ¿Basta correo y código por correo, o se pide e.firma/INE?
4. ¿Cuánto tiempo hay que conservar cada tipo de documento?
5. ¿Hay obligaciones de la AGPL que preocupen (ofrecer el código a usuarios de una versión modificada)?
6. ¿Se puede usar la e.firma del SAT para sellar documentos de la empresa?
7. Aviso de privacidad para datos de firmantes (IP, dispositivo, correo).
